# NICE Challenge Write-Ups

My collection of walkthroughs and methodology write-ups for the [NICE Challenge Project](https://nice-challenge.com/).

The NICE Challenge Project develops real-world cybersecurity challenges inside virtualized business environments, mapped to the [DoD Cyber Workforce Framework (DCWF)](https://public.cyber.mil/wid/dcwf/) and the [NICE Workforce Framework for Cybersecurity](https://niccs.cisa.gov/workforce-development/nice-framework).

Each folder in this repo is a self-contained write-up for one challenge, including the methodology I used, the exact commands run, screenshots from the challenge environment, and the findings I submitted through the workspace Documentation tab.

## Format

Every write-up follows the same shape so a reviewer (or future me) can scan it quickly:

1. **Scenario** - the situation as posed by the challenge.
2. **TL;DR** - the concealment technique and the recovery path in one paragraph.
3. **Tools used** - table of every command / package touched.
4. **Steps** - one section per command, showing the invocation, the on-screen result, and the reasoning.
5. **Findings and Recommendations** - what to report back to the "business."
6. **Key takeaway** - the single most important lesson from the challenge.

## Ethics and data handling

Everything in this repo comes from the isolated NICE Challenge lab environment. All names, credit-card numbers, expirations, and CVVs shown in the challenges are **synthetic test data** generated by the lab. Card data recovered during any walkthrough is redacted here (e.g. `9154****2957`) before publishing.
